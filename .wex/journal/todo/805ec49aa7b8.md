# Robots et personnes : collecte brute, signaux, filtre d'audience

Opened: 2026-10-21
Updated: 2026-11-18

## Constat

Portfolio : ~48 visiteurs/jour une fois les robots déclarés retirés (lecteurs en rafale avec UA de bureau, lecteurs lents, visites d'une page). Speech, premier jour en prod : ~79 000 pages de robots déclarés (ClaudeBot 64 150).

Décision (opérateur, 18/11) : garder les données brutes des robots ; consultation quotidienne, pas un outil SEO.

## Fait (18/11)

- Trois audiences (`AnalyticsAudience`) : `human`, `suspect` (page vue avec `robot` = raison), `declared` (sommes jour × robot × route dans `analytics_robot_day`, route vide pour l'existant). Sommes mensuelles par audience (`analytics_monthly.audience`, existant = `human`). Migrations speech `Version20261118100428`, portfolio `Version20261118100555`.
- Signaux : `headers` (pas d'Accept-Language, ou Chromium ≥ 80 sans Sec-Fetch-Mode), `burst` (`robot_minute_views`, 15), `cadence` (`robot_hourly_views`, 60). Requalification immédiate de toute la journée du visiteur. matomo/device-detector pour nommer les robots hors liste.
- Rétention par audience : `retention_months` (13), `suspect_retention_months` (1), `robot_retention_months` (3, 0 = non enregistrés).
- API : `audience=humans|robots|all` ; graphe `analytics-composition`.
- Écran : sélecteur Personnes / Robots / Tout (tableaux + chiffres), graphe de composition brut, robots toujours visibles, taille en base + rétention en pied de page.
